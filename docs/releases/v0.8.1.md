# v0.8.1

## Highlights

Diago v0.8.1 moves Lifecycle to schema v3 and bundles Archify 3.2.0 at `7e45f36c66de1254d5ad6ba1d878f6499ea269fd`. Archify lays out states and transitions automatically from an explicit `mainPath`. Diago includes 11 specialized renderers, a separate Architecture Explorer, and eight MCP tools.

## Changed

- Dataflow response and event arrows use Archify’s new compiler. When `meta.viewBox` is omitted, Dataflow sizes the canvas width to fit the stages and nodes.
- Sequence uses spread columns by default and fits its automatic canvas to the content. Set `meta.column_fit` to `"fixed"` to retain the previous fixed column spacing.
- The bundle includes Archify’s locale catalogs and the five explainer modules required by its output checker.
- The bundle and Archify-generated HTML carry the Apache 2.0 license, NOTICE, historical MIT grant, component notices, and the JetBrains Mono font license. [Third-party notices](https://github.com/amirtaherkhani/diago/blob/v0.8.1/THIRD_PARTY_NOTICES.md)
- The obsolete lifecycle v1 fixture is removed. Start new diagrams from the [maintained v3 example](https://github.com/amirtaherkhani/diago/blob/v0.8.1/examples/presentation/lifecycle.json).

## Breaking Changes

The CLI and MCP reject lifecycle v1 and v2 JSON. Convert those files by hand before validating or rendering. Diago provides no automatic converter.

## Migration

- Update the plugin through your host’s Diago marketplace. Start a new Codex session or run `/reload-plugins` in Claude Code. For the CLI or a directly registered MCP server, switch the source checkout to `v0.8.1`. Restart your agent session to reload a directly registered server. [Upgrade steps](https://github.com/amirtaherkhani/diago/blob/v0.8.1/docs/USAGE.md#upgrade-to-v081)
- Set `schema_version` to `3`, add `mainPath`, and remove the old layout fields from each lifecycle input. Preserve the meaning of old lanes and review the regenerated HTML. [Lifecycle migration guide](https://github.com/amirtaherkhani/diago/blob/v0.8.1/docs/lifecycle-v3.md)
