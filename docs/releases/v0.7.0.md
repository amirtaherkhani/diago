# v0.7.0

Draft for the next minor release; changes are relative to v0.6.0. This document does not publish a release or change the installed plugin version.

## Highlights

Evidence workflows expose independent source inspections, dependency joins, bounded retries, and conflicting claims through a deterministic planner for diagram authors.

## Added

- `diago evidence <workflow.json> [--json]` and the read-only `plan_evidence_workflow` MCP tool.
- A versioned workflow snapshot schema and checkout example with parallel API/storage inspections followed by contract verification.
- Ready-task selection respecting concurrency limits, dependency failures, reported elapsed time, and attempt budgets.
- Plan-compatible evidence with preserved citations and explicit conflicting, rejected, and unverified claim reports.

## Configuration

- Defaults: three concurrent tasks, two total attempts per node, and 15 seconds per attempt. The workflow supports up to 32 nodes.
- The host owns source inspection, verification, worker cancellation, and snapshot persistence. Mark tasks running before dispatch and stop timed-out work before retrying.
- CLI status is 0 for pending or complete work, 1 for terminal incomplete work, and 2 for invalid input. Check the report's `status` and `ok` before consuming evidence.
