# v0.8.0

## Highlights

Diago v0.8.0 adds dependency graphs, security matrices, and incident fishbones, bringing the catalog to 11 specialized renderers. Architecture Explorer is a separate output for a system with several views and shared components. The release includes eight MCP tools and four agent skills.

## Added

- Dependency graphs show direct dependencies, shared packages, and structural cycles. Security matrices show role and resource permissions with explicit unknowns. Fishbones group confirmed contributors, hypotheses, and ruled-out causes around an observed effect. Each model has a schema, advisor profile, and browser example. [Engineering models](https://github.com/amirtaherkhani/diago/blob/v0.8.0/docs/engineering-models.md)
- Build an offline Architecture Explorer with `diago explore` or the new `render_explorer` MCP tool. Define components once, reuse them across views, and inspect source evidence as you search or drill down. Both entry points return a compact artifact receipt. The public example maps Diago across five perspectives. [Explorer guide](https://github.com/amirtaherkhani/diago/blob/v0.8.0/docs/architecture-explorer.md)
- Nine connection-based renderers support guided walkthroughs. Select a numbered connection, see its highlighted arrow and endpoints, filter by component, or download an explanation in Markdown. Use playback or step manually with reduced motion. [Walkthrough guide](https://github.com/amirtaherkhani/diago/blob/v0.8.0/docs/guided-walkthrough.md)
- Six arrow types distinguish directed connections, responses, events, dependencies, bidirectional links, and associations. A compact legend shows the types used in each view, with full meanings available to assistive technology. Add an optional `arrow` field where the model supports it. [Arrow guide](https://github.com/amirtaherkhani/diago/blob/v0.8.0/docs/arrow-guide.md)
- Oh My Mermaid joins the weekly upstream checks as an MIT-licensed methodology source for architecture scanning and decomposition. [Integration review](https://github.com/amirtaherkhani/diago/blob/v0.8.0/docs/upstreams/oh-my-mermaid-review.md)

## Changed

- All 11 renderers and Explorer share Diago’s navy and yellow styling, compact logo, and accessible theme switch. Smaller arrowheads and lighter decoration keep the focus on the diagram. Evidence colors and Archify’s interaction and export features carry through to the branded output. Artifact receipts hash the final HTML. [Presentation and gallery](https://github.com/amirtaherkhani/diago/blob/v0.8.0/docs/renderer-presentation.md)
- Upstream discovery now tracks Archify’s `main` branch. Diago bundles commit `bb990b17` because the reviewed head `7e45f36` (Archify 3.2.0) rejects lifecycle schema v1 and v2 and breaks the dataflow arrow adapter.
- The partial upstream refresh updates the compatible Architecture Diagram Skill, UI UX Pro Max, and Diagram Design methodology snapshots. Oh My Mermaid was already current at review time. [Upstream review](https://github.com/amirtaherkhani/diago/blob/v0.8.0/docs/upstreams/2026-11-10-review.md)

## Fixed

- Explorer keyboard focus highlights the existing node card with a single outline.
- The Export button uses one yellow surface in both themes. Keyboard focus uses an underline.

## Migration

- Update the installed plugin in your host to use the new renderers and `render_explorer`. For the CLI or a directly registered MCP server, update the source checkout separately. [Upgrade steps](https://github.com/amirtaherkhani/diago/blob/v0.8.0/docs/USAGE.md#upgrade-to-v080)
- Existing diagram JSON works with v0.8.0. Regenerate exported HTML with the updated plugin or CLI to get the new appearance and controls.

## Configuration

- Append `?theme=light` or `?theme=dark` to a generated HTML URL to choose its initial theme.
- Run `node scripts/render-gallery.mjs tmp/renderer-gallery` from the repository root to preview all 11 renderers. Choose a new output directory for each run.
