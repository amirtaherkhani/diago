## Archify compatibility blockers

The reviewed head reports Archify 3.2.0. Its lifecycle schema accepts only version
3, requires `mainPath`, and rejects the old `lanes`, state `lane`/`col`, and
transition positioning fields. Running its validator against
`examples/presentation/lifecycle.json` exits 1 with those schema errors.

The attempted sync also exposed a separate adapter mismatch: dataflow edge
rendering moved from `render-dataflow.mjs` to `dataflow-compiler.mjs`, so Diago's
arrow extension must be adapted before the new runtime can render successfully.

A follow-up integration needs an explicit lifecycle compatibility or migration
strategy, the arrow adapter change, and updated sync paths for required locale
catalogs and license notices. The new runtime uses Apache-2.0 and preserves
historical MIT grants in `LICENSE-MIT`; retain its `NOTICE` and third-party
notices as well. The rejected runtime changes are not included in this refresh.
