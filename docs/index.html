Evidence workflows · available on main

Inspect independent sources together.

Plan source inspections and dependent cross-checks before authoring a diagram. Available from the source checkout; the published v0.6.0 plugin does not include this feature.

01

Follow dependencies

The planner identifies ready tasks within a concurrency limit. A completed branch can unlock its next task while unrelated work continues.

02

Contain failures

Keep successful source reports when another task fails. Track elapsed time, retry only eligible failures, and stop at the attempt budget.

03

Keep conflicts visible

Preserve citations and separate supported, unverified, and contradicted reports. Conflicting claims stay out of diagram-plan facts.

Source checkout · CLI 
node bin/diago.mjs evidence examples/checkout.evidence-workflow.json --json

The host performs inspections, verifies claims, and stops timed-out workers. Diago evaluates the supplied snapshot and returns the next eligible work; it does not launch agents or independently prove claims.

A few useful answers

What to know before your first diagram.

Quick answers about Diago, its MCP tools, and the artifacts you can keep.

What is Diago?

Diago is an open-source software engineering diagram toolkit for Codex and Claude Code. It combines agent skills, a local Model Context Protocol (MCP) server, and deterministic renderers to turn source evidence into interactive HTML diagrams.

Which diagrams can Diago create?

Diago supports eight views: architecture, sequence, workflow, dataflow, lifecycle, data model, timeline, and layers. Choose a view for the question you need to answer, such as request ordering or entity relationships. Explore all eight views.

Does Diago automatically understand my code?

Your agent inspects the repository and authors the diagram JSON. Diago helps plan the view, validate the input, render the result, and review the plan. Evidence references and assumptions remain explicit; you still review claims against their sources.

Does Diago need a hosted service or API key?

Diago runs locally on Node.js 18 or newer through stdio MCP or its CLI. It needs no separate Diago account, hosted endpoint, or API key. Your chosen agent's account, model access, and data-handling settings still apply. See setup options.

Can I share and update the diagrams?

Yes. Keep the source JSON and generated standalone HTML together. Open the HTML in a browser, share it for review, and regenerate it when the source changes. Check the content for private information before sharing outside your team.

Is Diago free, and which features are released?

Diago is available under the MIT license, with third-party notices preserved. The published v0.6.0 plugin includes eight views and six MCP tools. Evidence workflow planning adds a seventh tool on main and is not yet in that release. Check releases.
